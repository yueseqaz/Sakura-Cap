## Sakura-Cap 2.9.9

### 图片压缩与格式转换
- 输出格式新增 `None`，默认保持每张图片的原始格式，只做压缩；同格式重新编码若变大，则保留原始数据，避免出现越压越大的情况
- 移除长边限制，改用 0–100 的 Quality 滑条，保留原始像素尺寸；Quality 的 `None` 用于不主动降低画质的格式转换，WebP 使用无损编码，有损格式使用最高质量
- PNG / TIFF 支持通过降低颜色精度压缩，保留透明度；BMP / GIF 明确提示不支持质量调节
- 单张与批量图片均显示实际编码后的缩略图、逐张输出大小及合计；连续拖动时也会更新预览，旧任务不会覆盖最新设置
- 保持原格式时保留动画和多页图片，不会静默丢失后续帧或页面；原文件始终不会被覆盖

### 窗口行为
- 图片工具、翻译、AI、标注和音视频编辑等普通窗口不再默认置顶，也不再跟随所有桌面或覆盖其他应用的全屏空间
- 标题栏新增图钉，可按需手动置顶；菜单栏新增「已打开的窗口」，用于找回被遮挡或最小化的窗口
- 编辑器全屏时暂停手动置顶，退出后恢复用户选择；贴图、摄像头画中画、录制控制条及采集覆盖层保留必要的悬浮行为
- 普通确认框依附所属窗口；只有采集覆盖层的提示临时提升层级，关闭后恢复
- 移除授权完成时强行激活设置窗口的行为；后台检查更新不再主动抢焦点

### English

**Image compression and conversion.** Output format `None` preserves each source format. Same-format encoding keeps the original bytes whenever re-encoding would increase file size. A 0–100 Quality slider replaces the long-edge limit without resizing images. Quality `None` skips intentional quality reduction: WebP uses lossless encoding, while lossy formats use maximum quality. PNG / TIFF can reduce color precision while preserving transparency; BMP / GIF explicitly indicate that adjustable quality is unavailable. Single and batch previews show actual encoded thumbnails, per-image sizes, and totals during continuous slider adjustments. Keep-format mode preserves animation and multiple pages, and source files are never overwritten.

**Window behavior.** Ordinary tools, translation, AI, annotation, and media editors no longer float above other applications or follow every desktop. A title-bar pin enables always-on-top explicitly, and Open Windows in the menu bar restores covered or minimized documents. Fullscreen temporarily suspends manual pinning and restores the user's choice on exit. Pinned images, camera picture-in-picture, recording controls, and capture overlays retain their necessary floating behavior. Document confirmations use attached sheets; only capture-overlay alerts receive temporary elevation. Permission callbacks and background update checks no longer force the app to the foreground.

**Verification.** Release compilation and app packaging passed, alongside window presentation checks (33 assertions), image conversion / color picker checks (555 per language), image stitching checks (201 per language), chat / appearance / fullscreen checks (108, covering 12 ordinary window types), and in-place screenshot checks (293 per language).
