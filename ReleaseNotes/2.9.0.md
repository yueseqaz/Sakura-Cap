## Sakura-Cap 2.9.0

新增轻量原生图片拼接画布，修复区域截图与原地标注闪退，并更新中英文官网与真实界面截图。

### 图片拼接
- 从「工具 → 图片拼接」打开独立原生窗口，添加或拖入多张图片，在画布上自由摆放
- 支持等比缩放、对齐吸附、图片前后层级、撤销 / 重做、画布缩放和平移
- 一键横向 / 纵向排列，可设置图片间距，选择透明、白色或黑色背景
- 导出 PNG 或直接复制到剪贴板，导出范围自动包住全部图片
- 编辑时使用缩略预览，导出时逐张读取原图，关闭窗口释放画布；不引入新的第三方运行依赖

### 截图稳定性
- 修复区域截图空选或无效选区引发的闪退
- 过滤无效或无限坐标的光标区域，避免原地标注选区过小、控制柄越界时触发 AppKit 异常
- 修复文字标注重复提交，补充中英文界面回归验证

### 官网
- 更新录屏、截图、原地标注、图片拼接、OCR / AI 及音视频编辑的功能介绍
- 新增中文 / English 切换，包含完整英文文案、安装说明与无障碍标签
- 使用真实应用界面截图，素材仅含壁纸，不含其他应用窗口或个人信息
- 优化手机端展示，支持点击查看原图；仍为无框架、无新增依赖的静态页面

### 安装与兼容性
- 安装包及自动更新继续仅提供 DMG 和 SHA-256 校验文件，不提供 ZIP
- 仅支持 ZIP 更新的旧版请手动下载 DMG，退出旧版后将新版拖入 Applications 并替换
- macOS 13+；截图及窗口录制需要 macOS 14+；预编译安装包适用于 Apple Silicon
- 当前为 ad-hoc 签名，尚未经过 Apple 公证。首次打开请阅读 DMG 内的「安装前必看.txt」，按需授予屏幕录制等权限

### English

**New: native image stitching.** Open Tools → Image Stitching for a separate canvas. Drag in images, arrange them freely, resize proportionally, snap edges, adjust layer order, and undo or redo edits. Use horizontal or vertical layouts with configurable spacing and transparent, white, or black backgrounds. Export a PNG or copy the result. Thumbnail previews keep editing lightweight; originals are read individually during export. No new third-party runtime dependencies.

**More stable screenshots.** Fixes crashes caused by invalid cursor rectangles in empty, tiny, or offscreen selections during in-place annotation, plus duplicate text annotation submission. Includes Chinese and English regression coverage.

**A refreshed bilingual website.** Switch between Chinese and English for complete feature descriptions and installation guidance. Real app screenshots use wallpaper-only content, with no other app windows or personal information. Responsive, dependency-free static pages.

**Installation:** DMG and SHA-256 only; no ZIP packages. ZIP-only older updaters require one manual DMG installation. Requires macOS 13+ (macOS 14+ for screenshots and window recording). Prebuilt downloads are for Apple Silicon. The app is ad-hoc signed and not Apple-notarized; read the installation notes included in the DMG and grant permissions as needed.
