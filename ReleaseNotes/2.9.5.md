## Sakura-Cap 2.9.5

### 精准手动长截图
- 手动长截图改为逐段引导：每次滚动都会显示当前位移与绿色目标区，进入范围后才提交新段
- 页面停止滚动后等待连续稳定帧，避免触控板惯性滚动或页面动画造成中间帧拼接
- 滚动过头不会写入长图，可回滚到目标区后重试；支持撤销上一段
- 自动滚动保持原有流程，暂停或未匹配成功时可切换到精准手动模式

### 界面与文档
- 长截图控制条新增位移校准条、目标位置和当前段进度提示
- 更新中英文帮助文案与官网功能说明

### 验证
- Swift Release 构建与 `.app` 打包签名通过
- 图片拼接、原地截图回归测试通过
- 中英文官网结构与资源检查通过

### English

**Guided manual scrolling capture.** Manual long screenshots now advance one calibrated step at a time. A live displacement meter shows a green target zone; a segment is committed only after the page settles in that range. Overscroll is rejected and can be corrected by scrolling back, and the previous step can be undone. Auto-scroll keeps its existing workflow and can fall back to guided manual mode when needed.

**Interface and documentation.** The scrolling HUD now includes a target marker, current-step progress, and clearer bilingual guidance. The README and bilingual website describe the guided workflow.

**Verification.** Release compilation and app packaging passed, along with image-stitching, in-place screenshot, and bilingual website checks.
