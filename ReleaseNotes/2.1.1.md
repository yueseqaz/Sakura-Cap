## Sakura-Cap 2.1.1

翻译功能独立完善 + 一批体验修复。

### 翻译
- 菜单栏新增顶级「翻译」入口：文本翻译（输入/粘贴文字即译）与识别屏幕翻译（原截图翻译）；菜单顺序调整为 截屏 → 录屏 → 翻译
- 翻译窗口：原文可直接输入或粘贴，目标语言与翻译风格在窗口内就地切换（自动重译），OCR 结果与手动输入共用窗口、内容不丢
- 自定义服务商支持三种接口格式：OpenAI Chat / OpenAI Responses / Anthropic，获取模型列表按格式使用对应鉴权头
- 设置与翻译窗口明示当前生效的服务商与模型

### 修复
- 全局输入框支持 ⌘C/⌘V/⌘X/⌘A（菜单栏应用无主菜单导致快捷键失效）
- 翻译窗口输入框无法键入（文本视图初始尺寸为零）
- 翻译 / 视频工作台 / 图片标注窗口改为悬浮层级：点击其他应用不再被压到后面，切换桌面跟随显示
