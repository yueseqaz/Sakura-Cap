## Sakura-Cap 2.4.2

修复自动更新与 API Key 存储两项体验问题。

### 修复
- **自动更新**：GitHub API 被限流时改从 Homebrew cask 文件（raw.githubusercontent.com，不受 API 限流）获取版本号与 sha256，安装包校验值不再缺失，「缺少 sha256 校验值」导致无法自动安装的问题解决
- **API Key 回归 UserDefaults（base64 脱敏）**：不再使用钥匙串，彻底告别授权弹窗；偏好文件里也不再是肉眼可读的明文。2.3.0 及更早版本的明文 Key 升级后自动迁移为脱敏格式；曾使用 2.4.0–2.4.1（钥匙串版本）的用户需在设置里重填一次 Key
