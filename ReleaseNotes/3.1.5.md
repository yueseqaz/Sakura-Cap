## Sakura-Cap 3.1.5

3.1.5 brings watermark editing into the existing annotation and video workbench flows, with direct on-canvas editing and controls that stay close to the content being edited.

### Watermark editing
- Add full-screen tiled watermarks, single watermarks, or image watermarks from the existing workbench toolbar.
- Edit text directly inside the watermark on the image; double-click an existing watermark to edit it again.
- Reuse the annotation toolbar's line-width control for watermark text weight, keeping the editing surface compact.
- Drag the watermark box to move and resize it, rotate it with the 3D sphere handle, and adjust tilt and tiled spacing through the same control.
- Preview watermark changes live while editing, with undo support for committed changes.
- Apply watermarks to exported video timelines, including text and image assets.

### Interface fixes
- Remove the standalone watermark editor and the separate watermark toolbar controls that could widen the window.
- Keep the watermark action alongside the other workbench actions with the same borderless button treatment.
- Fix mirrored watermark text and keep the on-canvas text field aligned with the transformed watermark.

### Verification
- Swift build and release app build passed.
- App code-signature verification passed.
- DMG packaging and release verification run by the tag workflow.

### English

**Sakura-Cap 3.1.5** brings watermark editing into the existing annotation and video workbench flows, with direct on-canvas editing and compact controls that stay close to the content being edited.

**Watermark editing.** Add full-screen tiled, single, or image watermarks from the workbench toolbar. Text is edited directly inside the watermark on the image, and double-clicking an existing watermark reopens it. The annotation line-width control adjusts watermark text weight. Drag the watermark box to move and resize it, rotate it with the 3D sphere handle, and use the same control to adjust tilt and tiled spacing. Changes preview live and committed edits support undo. Watermarks are also rendered into exported video timelines.

**Interface fixes.** The standalone watermark editor and separate watermark toolbar controls are removed so the window stays compact. The watermark action uses the same button treatment as the other workbench actions. Mirrored watermark text is fixed, and the on-canvas text field follows the transformed watermark.

**Verification.** Swift build, release app build, and app code-signature verification passed. DMG packaging and release verification run by the tag workflow.
