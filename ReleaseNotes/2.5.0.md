## Sakura-Cap 2.5.0

长截图专项重做 + 权限与焦点体验修复。

### 长截图（滚动截屏）
- **框选后先选滚动方式**：自动滚动 / 手动滚动二选一才开始，选自动但缺辅助功能权限时自动落到手动模式
- **修复「明明页面很长却拼不上」**：Retina 屏上滚动落点几乎都是非整数像素，旧匹配算法直接判定「没滚动」——自动、手动全都失效。新算法（纵向模糊 + 逐行打分截尾均值 + 双阈值）稳定识别小数位移，固定顶栏/悬浮元素、懒加载内容也不再干扰
- **手动模式真正可用**：自动滚动停下或暂停后自动切入手动采样，滚动页面实时拼接，随时可点「自动滚动」切回
- **自动滚动更耐性**：每步先常规步长、匹配不到加大步长重发，两轮尝试后才放弃并切手动
- **控制条 / 预览不再被截进长图**：自动避开框选区域摆放；并修复过滤器竞态（此前窗口列表未注册完就建过滤器，排除列表为空导致状态条、预览块漏进画面）
- 新增匹配调试日志（`log stream --predicate 'process == "SakuraCap"' --level debug` 可看每次匹配分数）

### 权限
- **麦克风权限不再随启动弹窗**：只在真正用到时申请——开始录制且勾选了麦克风、或在面板/HUD 主动打开麦克风开关；拒绝授权自动降级为不带麦克风继续录

### 焦点
- **框选结束后把焦点还给原应用**（截图 / 录屏 / OCR / 长截图等全部场景）：不再把更新弹窗、菜单面板顶到你正在操作的页面前；需要你注意的窗口（编辑器、结果窗）仍会正常弹出

### 升级提示
- ad-hoc 签名应用每次重编译后 TCC 授权可能失效，若升级后重新弹屏幕录制/麦克风授权，重新允许即可
