## Sakura-Cap 2.4.0

安全与健壮性专项：API Key 进钥匙串、保存不再「假成功」、修复录音竞态与滚动截屏泄漏，并接入 CI 门禁。

### 安全
- **API Key 迁入系统钥匙串（Keychain）**：翻译 / AI 的密钥不再以明文存在配置文件里；从旧版本升级自动完成迁移，迁移失败时保留原值、绝不丢 Key（首次读取可能弹一次系统授权框，选「始终允许」即可）
- **自动更新强制 sha256 校验**：安装包摘要缺失时拒绝自动安装并引导去发布页手动下载，杜绝被替换的安装包

### 修复：失败如实相告
- 截图保存失败（磁盘满 / 无权限）不再弹 Finder、不再误报「已保存」，明确提示原因且不关窗，可重试
- 导出后勾选「删除原文件」：删除失败时如实提示「请手动删除」，不再谎报已删除
- PNG 写入（截图保存 / 对比图 / 截帧）全部改为原子写，写入中断不再留半张图
- GIF 导出失败自动清理坏文件，不再残留 0 字节残留
- AI 聊天记录：保存失败即时提示；无法读取的历史文件会提示数量并跳过（文件保留在原处，不删）

### 修复：稳定性
- 录音链路两处跨线程竞态（系统声回调、麦克风缓冲接线）对齐视频链路的线程安全写法，反复开始/停止更稳
- 滚动截屏重复触发不再泄漏旧会话的定时器与事件监听（此前会留下持续后台截屏的「幽灵」）
- 打开损坏的音视频文件不再可能闪退，改为在编辑器里提示无法读取
- 反复开关剪辑 / 音频编辑 / 翻译 / 对比窗口不再累积观察者注册（缓慢内存增长）

### 工程化（内部改进）
- 新增 CI：每次 push / PR 自动构建 .app 并跑坐标换算断言脚本
- 视频工作台与音频编辑器的窗口层合并为统一呈现层（净删约 200 行重复代码）
- 点击标记 / 按键显示引擎自订阅设置开关，UI 只改设置即生效，删除四处手写启停
- 选区用途路由（截图 / OCR / 翻译 / 问 AI / 录制…）抽出独立 Coordinator

### 升级提示
- ad-hoc 签名应用升级后，首次使用翻译 / AI 会弹一次钥匙串授权框，选「始终允许」即可
