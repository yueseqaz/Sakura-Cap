## Sakura-Cap 2.3.0

录音功能：菜单栏一键录音、专属音频编辑器。

### 录音
- 菜单「录音」（位于开始录制之后）：录制系统声音 / 麦克风 / 两者同时，输出 m4a
  （系统声与麦克风分轨）；支持暂停/继续，暂停间隙自动无缝
- 悬浮录音条：脉动红点 + 律动条 + 等宽计时 + 暂停/停止，可拖动，
  不进入截屏/录屏画面
- 权限引导：系统声依赖屏幕录制授权，麦克风单独检查并跳转设置

### 音频编辑器（专属页面）
- 录音结束自动打开（可在设置关闭）；菜单「编辑音频…」可打开任意音频文件
- 上部大波形展示（分音轨、剪掉区域压暗、音量段覆盖显示、可拖动定位）
- 下部时间轴：片段行（拖边缘裁剪 / 拖动排序 / S 分割 / Delete 删除）+
  各音轨音量行（拖拽创建音量段、夹点拉伸、就地静音或调音量）
- 片段操作：音量（0–200%）、声音淡入淡出、片段静音、删除
- 播放结束再次播放从头开始；快捷键 空格 / ←→ / S / ⌘Z
- 导出 m4a（无编辑时直通秒出）；弹窗文案区分录音与录屏

### 其他
- 修复：SCK 采集系统声必须同时挂视频输出（仅音频输出时不送缓冲）
- 调试直开：`-workbench` 按文件类型路由到视频工作台 / 音频编辑器，`-audiotest`
