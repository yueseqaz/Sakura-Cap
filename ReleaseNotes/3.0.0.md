## Sakura-Cap 3.0.0

3.0.0 把后期工作台从「手动剪辑」推进到「自动出片」：录制时的点击可以一键变成聚焦动画，说话内容可以一键变成字幕，字幕还能直接在时间轴上编辑。

### 点击自动聚焦
- 录制期间自动记录每一次点击的位置与时间，后期工作台新增「自动聚焦」按钮，一键根据点击生成聚焦段（默认 2× 放大）
- 连续且位置相近的点击自动归为一段，段前后各留缓冲时间，相邻段不重叠，避免镜头频繁跳动
- 生成的聚焦段与手动创建完全一致：时间轴上可拖动两端夹点调整范围，属性面板可调放大倍数，⌘Z 可整批撤销
- 与「点击标记」显示完全解耦：开关点击标记不影响自动聚焦；点击记录只依赖「输入监控」权限

### 字幕转写
- 工作台新增「转写字幕」：把当前剪辑的音频交给系统语音识别，自动生成字幕，语言跟随系统设置，无需选择
- macOS 26 及以上使用全新的 SpeechAnalyzer 引擎：完全离线、长音频完整覆盖、自带精确时间索引；缺少语言模型时会自动下载
- 旧版 macOS 使用 SFSpeechRecognizer 分块识别（设备端优先、服务端兜底），首次使用会请求「语音识别」权限
- 转写对象是「当前剪辑后的时间线」：剪掉的片段、静音的段落不会产生字幕；转写完成的按钮自动置灰，删除全部字幕后可重新转写
- 已生成某条语音模型不可用等错误会明确提示，不再静默丢失内容

### 字幕轨与字幕编辑
- 时间轴底部新增字幕轨（音频编辑模式同样可用）：转写结果以字幕条形式呈现，可直接编辑
- 点击字幕条选中后，在右侧属性面板直接修改文本，识别错字随手改
- 拖动字幕条两端夹点调整起止时间；拖动字幕条本体整体移动；在空白处拖拽可创建新字幕条；支持删除与 ⌘Z 撤销
- 字幕锚定「源时间」，与聚焦 / 标注一致：转写之后再删剪片段，字幕跟着内容走，删除片段范围内的字幕自动清理
- 播放预览底部实时显示当前字幕浮层；「导出字幕」一键输出 SRT 文件（时间已换算回导出视频的时间轴）

### 界面调整
- 移除视频裁剪页时间轴右下角的缩放控件（− / 滑杆 / +）：打开视频时自动铺满，触控板捏合缩放保留

### 验证
- Swift Release 构建与 `.app` 打包签名通过
- 音频提取与识别管线以位置已知的合成语音做对照探针验证：合成 → M4A 导出完整无损，识别结果全程覆盖无缺段
- 自动聚焦在实机录制流程验证：点击分组、缓冲、缩放动画与撤销符合预期
- 字幕轨的创建 / 移动 / 调时 / 改文本 / 删除与 SRT 导出实测通过；关闭「点击标记」后箭头不再显示、点击记录持续工作

### English

**3.0.0 moves the workbench from manual editing to automatic results:** recorded clicks turn into focus animations with one tap, and speech turns into editable captions on the timeline.

**Click auto focus.** Every click is recorded with its position and time during capture. A new Auto Focus button in the workbench generates focus segments from those clicks (2× zoom by default). Rapid, nearby clicks merge into one segment with lead-in/out buffers, and adjacent segments never overlap. Generated segments behave exactly like manual ones: drag the handles on the timeline, adjust zoom in the panel, undo the whole batch with ⌘Z. The feature is fully decoupled from click-marker display — toggling markers never affects click recording, which only needs Input Monitoring permission.

**Speech transcription.** A new Transcribe Captions action runs system speech recognition over the current edit and generates captions in the system language. On macOS 26 and later it uses the new SpeechAnalyzer engine: fully on-device, complete coverage of long audio, precise time indexing, and automatic language-model downloads. Older systems fall back to chunked SFSpeechRecognizer (on-device preferred, server fallback) and ask for Speech Recognition permission on first use. Transcription runs on the edited timeline, so cut or muted portions never produce captions; the button disables after transcription and re-enables once all captions are deleted. Unavailable speech models now surface a clear error instead of silently dropping content.

**Captions lane and editing.** The timeline gains a captions lane (also in audio-only mode) where transcribed cues appear as editable segments. Select a cue to fix its text in the properties panel; drag the handles to retime it; drag its body to move it; drag on empty lane space to create a new cue; delete or undo with ⌘Z. Captions are anchored to source time like focus and annotation effects, so later edits keep captions attached to their content, and captions inside deleted ranges are cleaned up automatically. A live caption overlay appears in the preview, and Export Captions writes an SRT file with times mapped back to the exported timeline.

**Interface changes.** The zoom control (− / slider / +) at the bottom-right of the timeline has been removed: the timeline fits the video automatically on open, and pinch-to-zoom remains available.

**Verification.** Release build and app packaging passed. The audio extraction and recognition pipeline was validated with a probe using synthetic speech at known positions: composition-to-M4A export preserves audio end to end, and recognition covers the full duration without missing segments. Auto focus was verified in real recording sessions (grouping, buffering, zoom animation, undo). Caption lane create / move / retime / edit / delete and SRT export were exercised manually; click-marker arrows no longer appear when markers are disabled while recording continues to log clicks.
