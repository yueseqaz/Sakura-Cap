## Sakura-Cap 2.1.0

录屏后期工作台：录制完成后的编辑页全面重做，从"简单裁剪"升级为轻量剪辑台。

### 后期工作台（替换原裁剪页）
- 四区布局：顶部工具栏 / 中央预览 / 右侧属性面板 / 底部多轨时间轴
- 多轨时间轴：视频轨缩略图条、系统声音与麦克风分轨波形、聚焦轨与标注轨；
  时间轴贴合视频实际时长，缩放（⌘滚轮 / 触控板捏合 / 滑杆）不显示片尾空白
- 轨道直接拖拽创建段：聚焦轨拖出聚焦段、标注轨拖出标注段、音频轨拖出音量段，
  两端夹点可拉伸调整范围
- 剪辑：分割（S）、删除、拖边缘裁剪、拖动排序、撤销重做（⌘Z / ⇧⌘Z）、吸附
- 画面聚焦：在预览画面上自由框选区域，放大倍数（1–6×）由右侧滑杆独立调节
- 标注：画笔 / 箭头 / 形状 / 文字 / 序号 / 马赛克，工具栏悬浮在预览下方，就地绘制
- 音频：整轨音量与静音、音量段（某一段静音或降低音量）、片段声音淡入淡出
- 视频轨悬停显示对应帧预览与时间码
- 导出：MP4（无编辑时直通秒出）/ GIF / 截帧；快捷键空格、←→（⇧ 跳 1 秒）、F 全屏
- 调试直开：`SakuraCap -workbench <视频路径>`

### 摄像头画中画
