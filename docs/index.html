工具很多。

RECORD / 录屏

范围由你定，
节奏也由你定。

全屏、框选区域或单独录制窗口；多屏可并行各存一份。录制前在悬浮 HUD 调好分辨率、系统声音、麦克风和摄像头，录制中随时暂停、继续或结束。

CAPTURE / 截图

只截需要的。
长图也不费力。

全屏、区域截图后直接进入编辑。滚动长截图会自动向下滚动并拼接，遇到需要停下的地方，你可以随时打断。小范围仍按显示器原生像素捕捉。

03 / 06

ANNOTATE / 标注

指出重点，
不破坏画面。

图片编辑器支持选中后移动和修改标注，缩放、平移也不会让图片外的空白变成画布。不想先截图？打开实时屏幕标注，直接在桌面上绘制和测量。

04 / 06

RECOGNIZE / 识别

画面里的信息，
不必重新输入。

在图片中框选文字，使用 macOS Vision 离线 OCR；框选二维码即可识别内容。翻译也从选区开始，不用先手动摘录文字。
