Sakura-Cap

菜单栏常驻的极简 Mac 录屏 / 截图工具。点一下就能开录，录完顺手裁一刀、标一标，截图取字一步到位。

macOS 13+ 零第三方依赖 开源免费 中文 / English
下载最新版 GitHub 仓库

功能

录音、截图、标注，一条龙。

🎬

录屏

全屏（单屏 / 多屏并行）、框选区域、窗口录制；录制中可暂停 / 继续 / 停止。

🎚️

悬浮控制条

就地选输出分辨率、麦克风与系统声音、摄像头、点击标记与按键显示，点 ▶ 才开始。

✂️

录制后裁剪

录完自动进裁剪页：拖动区间、只循环预览选中片段，导出为新文件（可选删除原文件）。

📸

截图

全屏 / 区域截图，完成后进入标注编辑器，保存或直接拷贝到剪贴板。

🔍

OCR 取字

框选任意区域，系统 Vision 离线识别文字，一键复制到剪贴板。

📜

滚动截屏

边滚动边按重叠自动拼接成一张长图，右侧实时预览。

🖊️

标注编辑器

画笔、箭头、矩形、文字、序号、马赛克（像素块/模糊/六边形）、裁剪；可二次编辑、撤销重做、滚轮缩放。

📌

「定住」贴图

把结果干净地贴在屏幕上当参考图：红虚线框、可拖动、滚轮等比缩放、右上角关闭。

👆

点击标记 & 按键显示

录制时标出鼠标点击（指向箭头）、在角落显示所按按键。

🎥

摄像头画中画

录制时在角落叠一个可拖动的圆角摄像头小窗，可选具体设备。

⌨️

自定义快捷键

每个动作都能绑快捷键：录制、截图、OCR、滚动截屏，默认留空由你设置。

🌙

录屏勿扰 & 提示音

可选录制时切换专注模式；开始 / 结束提示音，且不会被录进视频。

安装

推荐用 Homebrew。

brew tap yueseqaz/sakura-cap https://github.com/yueseqaz/Sakura-Cap
brew trust yueseqaz/sakura-cap
brew install --cask sakura-cap

或者从源码构建：

git clone https://github.com/yueseqaz/Sakura-Cap.git
cd Sakura-Cap
./run.sh

应用未公证，首次打开若被拦截，请右键「打开」，或在「系统设置 → 隐私与安全性」中允许；按需授予屏幕录制 / 麦克风 / 摄像头 / 输入监控权限。
