The small details matter

细节里，也很周到。

每个功能都有明确的用途，不用为了一个小动作打开一整套工作流。

⌘

全局快捷键

录屏、截图、OCR 等动作可自行绑定快捷键；默认不占用系统组合键。

◉

镜头预览

从菜单栏打开摄像头预览，可调窗口大小，录制时也能使用画中画。

▧

实时屏幕标注

在桌面上画箭头、序号或马赛克；穿透模式下还能继续操作下方窗口。

◫

窗口与长图

录制单个窗口，也能滚动拼接长截图；完成后继续编辑而不是立刻保存。

↔

识别与翻译

OCR 使用系统 Vision 离线识别；翻译服务可自行配置，密钥留在本机。

◈

权限可见

屏幕录制、摄像头、麦克风与输入监控集中展示，按需授权。

Light where it counts

轻巧，不是
一句口号。

菜单栏常驻，没有 Dock 图标。使用 macOS 的 ScreenCaptureKit、AVFoundation 和 Vision，运行时不依赖第三方框架。

≈25 MB
空闲状态常驻内存（RSS）

安静待命时占用约 25 MB。录制、摄像头、标注和不同显示器配置都会增加内存使用。

也可以用 Homebrew 安装

复制命令，在终端中运行。

$ brew tap yueseqaz/sakura-cap https://github.com/yueseqaz/Sakura-Cap
$ brew trust yueseqaz/sakura-cap
$ brew install --cask sakura-cap
macOS 13+。应用尚未经过 Apple 公证；首次打开若被拦截，请在「系统设置 → 隐私与安全性」中允许。录屏需要屏幕录制权限，其他权限按需授权。
