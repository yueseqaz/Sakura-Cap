# 官网界面截图

2026-10-27 更新，界面来自 `bcca538` 代码构建，不是 HTML 模拟图或回归测试截图。
这些截图沿用至 2.9.0 官网；图片拼接在 2.9.0 中正式发布。

## 素材与隐私

- `inline.webp`：真实原地标注视图、可调选区、底部工具栏与右侧快捷栏。
- `editor.webp`：真实图片标注窗口，箭头由实际标注工具绘制。
- `stitch.webp`：真实图片拼接窗口，素材为 macOS 自带的 Sonoma / Mac Blue 壁纸。
- `workbench.webp`：真实视频工作台与实际创建的聚焦片段；输入为纯壁纸生成的视频，没有采集其他应用或声音。
- `convert.webp`：真实图片转换窗口，展示上述壁纸的实际尺寸及编码体积预估。
- `recorder.webp`：真实录制控制条的准备状态，未启动屏幕或音频录制；仅裁去周围多余壁纸。

桌面背景仅使用经用户允许的壁纸，不包含桌面文件、菜单栏账号、其他应用窗口、消息或设置凭据。
编辑器等独立窗口使用窗口级截图；原地标注和录制浮层从运行中的 AppKit 视图回读，按真实屏幕位置组合。
没有重新绘制工具界面，也没有为拍摄修改产品代码。WebP 不保留 EXIF、位置或原始路径元数据。

## 本地重拍

运行 `bash Scripts/capture_website.sh`。辅助构建采用独立 bundle / UserDefaults 域，
不读取正式应用的服务配置和历史，不启动屏幕采集。它会读取当前桌面壁纸，
因此重拍前请先确认壁纸适合公开展示。只构建可加 `--build-only`。

Command-1 到 Command-6 切换原地标注、图片标注、拼接、视频工作台、格式转换和录制准备。
切换后自动将原生视图导出到本目录；调整后可用 Command-Shift-P 重新导出，Command-Q 退出。
辅助文件位于被 Git 忽略的 `build/website-capture/`。

视频预览包含 AVPlayer 图层，重拍时需检查图层是否完整；必要时使用仅针对辅助应用窗口的原生截图。
不要以全屏截图代替窗口截图。窗口标题栏出现的紫色系统共享标记属于 macOS 界面，不是产品控件。

上线前逐张检查隐私、画面完整性及版本一致性；若替换图片，需同步 `docs/index.html` 中的宽高属性。
最长边不超过 2200 px，WebP 质量 88；不放大低于此尺寸的原图。
