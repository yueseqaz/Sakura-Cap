# Sakura-Cap

**[中文](README.md)** | **[English](README.en.md)** | **[日本語](README.ja.md)**

**メニューバー常駐型のミニマルな Mac 画面収録・スクリーンショットツール。** 軽く、速く、クリーンに——メニューバーのワンクリックで収録開始、終わったらそのままトリミング＆注釈、スクリーンショットからのテキスト抽出もワンステップ。

Sakura-Cap は「画面を録る・撮る」に特化しています：Dock アイコンなし、余計なウィンドウなし、起動は速く動作は軽量。収録前にフローティング操作バーで解像度・マイク・カメラ・クリックマーク・キー表示をその場で調整し、収録終了後は自動でトリミング画面へ、スクリーンショットはそのまま注釈エディタへ進みます。

## 機能

**画面収録**
- フルスクリーン（単一ディスプレイ / 全ディスプレイ並行・それぞれ 1 ファイル）、範囲選択、ウィンドウ収録（システム共有ピッカー）
- フローティング操作バー：待機状態で **▶** を押してから収録開始、収録中は一時停止 / 再開 / 停止
- その場で調整：出力解像度（オリジナル / 1080p / 720p）、マイク、システムサウンド、カメラ、クリックマーク、キー表示
- 一時停止した区間はタイムラインから除外され、継ぎ目のない出力
- 収録アシスト：マウスクリックマーク（矢印）、キー表示、開始 / 終了サウンド、カメラのピクチャーインピクチャー、3 秒カウントダウン

**スクリーンショット**
- フル画面 / 範囲選択
- **OCR**：範囲選択後にシステム Vision でオフライン認識、テキストをそのままクリップボードへ
- **スクロールキャプチャ（ロングスクリーンショット）**：範囲選択後に「自動スクロール / 手動スクロール」を選択。スクロールに合わせて重なりから自動で縦につなぎ合わせ、1 枚のロング画像に。右側にリアルタイムプレビュー
  - 自動スクロールは手を離して OK、手動は自分でスクロールしながらリアルタイムに結合、いつでも切り替え可能
  - Retina の小数ピクセルずれや、固定ヘッダー・追尾要素・遅延読み込みにも強いマッチング
  - 操作バーとプレビューは選択範囲を避けて配置され、画面に写り込みません
- スクリーンショットは**直接保存されません**——注釈エディタで保存 / クリップボードへコピー / 破棄を選べます

**注釈エディタ**（スクリーンショットと「画像に注釈…」で共用）
- ツール：ペン、矢印、矩形、テキスト、番号、モザイク（ピクセル化 / ぼかし / 六角形）、トリミング
- 描いた内容は**後から再編集可能**：選択して移動、色・線の太さの変更、矢印の向き変更、削除
- 取り消し / やり直し、ホイールでズーム、⌘+ホイールでパン、ワンクリック「ウィンドウに合わせる」
- トリミングは即時反映（画像と注釈をまとめて）
- **ピン留め**：結果をきれいなまま画面に貼り付け（赤い点線枠、ドラッグ移動、ホイール / ボタンで等倍ズーム、右上のボタンで閉じる）

**その他**
- グローバルショートカット：フル / ウィンドウ / 範囲収録、フル / 範囲スクリーンショット、OCR、スクロールキャプチャ。**初期設定は空欄・お好みで設定**
- マイク / カメラはデバイス単位で選択可能（設定画面と HUD のどちらでも）
- 権限は「権限」タブに集約：画面収録 / マイク / 入力監視 / カメラ。マイク権限は実際に使うときだけ要求します
- 範囲選択が終わるとフォーカスは元のアプリへ返ります——更新ダイアログやメニューが作業中の画面の前に割り込むことはありません
- ログイン時に起動、収録中のおやすみモード（ショートカット）、完了通知（Finder で表示）、ディスプレイのホットプラグ対応、中国語 / 英語 UI

## インストール

### Homebrew（推奨）

```bash
brew tap yueseqaz/sakura-cap https://github.com/yueseqaz/Sakura-Cap
brew trust yueseqaz/sakura-cap          # 新しい Homebrew ではサードパーティ Tap の信頼が先に必要
brew install --cask sakura-cap
```

### ソースからビルド

```bash
git clone https://github.com/yueseqaz/Sakura-Cap.git
cd Sakura-Cap
./run.sh
```

> 本アプリは ad-hoc 署名で、公証（notarization）はしていません。初回起動時にブロックされた場合は、右クリック→「開く」、または「システム設定 → プライバシーとセキュリティ」で許可してください。

## 使い方

1. メニューバーのアイコン →「収録開始 / スクリーンショット / 画像に注釈…」、または設定したグローバルショートカット
2. 範囲を選ぶと画面下部にフローティング操作バーが出ます：解像度を選び、マイク / システムサウンド / カメラ / クリックマーク / キー表示を切り替え、**▶** で開始
3. 収録中は一時停止 / 再開 / 停止が可能。スクリーンショット / OCR / スクロールキャプチャは「スクリーンショット」サブメニューに（スクロールキャプチャは範囲選択後に自動 / 手動を選択）
4. 収録終了後は自動で**トリミング画面**へ。スクリーンショット / ロングスクリーンショットは**注釈エディタ**へ（保存・コピー・ピン留め）

## 動作環境

- macOS 13 以降
- 初回使用時に**画面収録**権限が必要です。マイク・カメラ・入力監視は任意（許可がない場合はその機能だけが無効になり、収録自体には影響しません）

## 開発

技術スタック、ビルド方法、署名と権限、内部規約や既知の落とし穴 → **[docs/DEVELOPMENT.md](docs/DEVELOPMENT.md)**（中国語）

- Swift 5.9 + SwiftUI / AppKit。収録は ScreenCaptureKit、エンコードは AVFoundation、OCR は Vision
- サードパーティ依存ゼロ・システムフレームワークのみ。Command Line Tools だけでビルドし、`.xcodeproj` は一切ありません
