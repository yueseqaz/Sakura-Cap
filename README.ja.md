# Sakura-Cap

**[中文](README.md)** | **[English](README.en.md)** | **[日本語](README.ja.md)**

**メニューバー常駐型のミニマルな Mac ツール：画面収録・録音・スクリーンショット・AI。** 軽く、速く、クリーンに——メニューバーのワンクリックで収録開始、終わったらそのまま編集＆注釈、スクリーンショットからのテキスト抽出もワンステップ、画面をそのまま AI に質問することも。

Sakura-Cap は「画面を録る・撮る」に特化しています：Dock アイコンなし、余計なウィンドウなし、起動は速く動作は軽量。収録前にフローティング操作バーで解像度・マイク・カメラ・クリックマーク・キー表示をその場で調整し、収録終了後は自動で後処理ワークベンチへ、スクリーンショットはそのまま注釈エディタへ進みます。

## 機能

**画面収録**
- フルスクリーン（単一ディスプレイ / 全ディスプレイ並行・それぞれ 1 ファイル）、範囲選択、ウィンドウ収録（システム共有ピッカー）
- フローティング操作バー：待機状態で **▶** を押してから収録開始、収録中は一時停止 / 再開 / 停止
- その場で調整：出力解像度（オリジナル / 1080p / 720p）、マイク、システムサウンド、カメラ、クリックマーク、キー表示
- 一時停止した区間はタイムラインから除外され、継ぎ目のない出力
- 収録アシスト：マウスクリックマーク（矢印）、キー表示、開始 / 終了サウンド、カメラのピクチャーインピクチャー、3 秒カウントダウン

**録音**
- メニューバーからワンクリック：システムサウンド / マイク / 両方。m4a 出力で、システムサウンドとマイクは**別トラック**
- 一時停止 / 再開に対応、停止間のギャップは自動でシームレスに接合
- フローティング録音バー：脉動する赤ドット + レベルメーター + タイマー、ドラッグ移動可能、スクリーンショットや収録画面には写り込みません
- 録音終了後は自動でオーディオエディタへ（設定でオフ可能）

**スクリーンショット**
- フル画面 / 範囲選択
- **OCR**：範囲選択後にシステム Vision でオフライン認識、テキストをそのままクリップボードへ
- **QR コード認識**：範囲選択で読み取り・コピー
- **画像ホストへアップロード**：注釈エディタの右側からワンクリックで画像全体（注釈込み）をアップロード。**S3 互換オブジェクトストレージ**（Cloudflare R2 / MinIO / 各クラウド）、**GitHub リポジトリ**、**カスタム API**（multipart、JSON パスまたは正規表現でリンク解析）に対応。成功後、選択した形式（URL 直リンク / Markdown / HTML）でリンクを自動的にクリップボードへコピーします
- **スクロールキャプチャ（ロングスクリーンショット）**：範囲選択後に「自動スクロール / 手動スクロール」を選択。スクロールに合わせて重なりから自動で縦につなぎ合わせ、1 枚のロング画像に。右側にリアルタイムプレビュー
  - 自動スクロールは手を離して OK、手動は自分でスクロールしながらリアルタイムに結合、いつでも切り替え可能
  - Retina の小数ピクセルずれや、固定ヘッダー・追尾要素・遅延読み込みにも強いマッチング
  - 操作バーとプレビューは選択範囲を避けて配置され、画面に写り込みません
- スクリーンショットは**直接保存されません**——注釈エディタで保存 / クリップボードへコピー / 破棄を選べます

**翻訳と AI**（サービス設定は共通 1 式）
- **テキスト翻訳**ウィンドウ + **画面翻訳**（範囲選択 → OCR → AI 翻訳）、翻訳スタイルも設定可能
- **AI チャット**：Markdown 完全レンダリング、ストリーミング出力（生成中に停止可能）、画像添付、⏎ 送信 / ⇧⏎ 改行
- **スクリーンショットで AI に質問**：画像をそのまま送る（ビジョンモデル）か、先に OCR してテキストで送る（テキスト専用モデル向け）
- **注釈ページの「AI に質問」**：注釈ごと画像全体をワンクリックで送信
- **チャット履歴**：セッション一覧、完全削除（画像ファイルも一緒に）；長い会話は自動ローリング要約で文脈を維持
- **OpenAI Chat / OpenAI Responses / Anthropic** の 3 形式に対応、いずれもストリーミングとマルチモーダル画像をサポート

**後処理：ビデオワークベンチ**（収録終了後に自動で開く）
- マルチトラックタイムライン：動画サムネイル、システムサウンド / マイク別の波形、フォーカストラック、注釈トラック
- 編集：分割（S）、削除、端ドラッグでトリミング、並べ替え、取り消し / やり直し（⌘Z / ⇧⌘Z）、スナップ
- トラック上で直接ドラッグしてセグメント作成：フォーカス・注釈・音量セグメント、端ハンドルで範囲調整
- **スポットライトフォーカス**：プレビュー上で範囲を選び 1–6 倍で拡大、倍率は独立調整
- その場で注釈：ペン / 矢印 / 図形 / テキスト / 番号 / モザイク、ツールバーはプレビュー下に浮遊
- オーディオ：トラック単位の音量とミュート、音量セグメント（部分ミュート / 減衰）、フェード
- **MP4（無編集ならパススルーで即時）/ GIF / フレーム書き出し**；Space 再生、←→ コマ送り（⇧ で 1 秒）、⌘ホイールでタイムラインズーム

**後処理：オーディオエディタ**
- 上部に大きな波形（トラック別、トリミング範囲は暗表示、クリックでシーク）、下部にセグメント行 + トラック音量行
- セグメントのトリミング / 分割 / 並べ替え、音量セグメント、フェード、部分ミュート、音量 0–200%
- m4a 書き出し（無編集ならパススルーで即時）；Space / ←→ / S / ⌘Z ショートカット
- メニュー「オーディオを編集…」で任意の音声ファイルを編集可能

**注釈エディタ**（スクリーンショットと「画像に注釈…」で共用）
- ツール：ペン、矢印、矩形、テキスト、番号、モザイク（ピクセル化 / ぼかし / 六角形）、トリミング
- 描いた内容は**後から再編集可能**：選択して移動、色・線の太さの変更、矢印の向き変更、削除
- 取り消し / やり直し、ホイールでズーム、⌘+ホイールでパン、ワンクリック「ウィンドウに合わせる」
- トリミングは即時反映（画像と注釈をまとめて）
- **ピン留め**：結果をきれいなまま画面に貼り付け（赤い点線枠、ドラッグ移動、ホイール / ボタンで等倍ズーム、右上のボタンで閉じる）

**その他**
- グローバルショートカット：フル / ウィンドウ / 範囲収録、フル / 範囲スクリーンショット、OCR、スクロールキャプチャ。**初期設定は空欄・お好みで設定**
- ツールメニュー：**画面注釈**（全画面にそのまま描画）、**カメラプレビュー**（カメラフロート窓）、画像に注釈、動画トリミング、オーディオ編集、**比較**（2 枚の画像を並べて全体比較）、**カラーピッカー**（画面上の任意の色を抽出）、**オーディオ抽出**（動画の音声トラックを m4a で書き出し）
- カメラのピクチャーインピクチャーに**ハサミボタン**：現在のフレームをワンクリックで注釈エディタへ
- マイク / カメラはデバイス単位で選択可能（設定画面と HUD のどちらでも）
- 権限は「権限」タブに集約：画面収録 / マイク / 入力監視 / カメラ。マイク権限は実際に使うときだけ要求します
- 範囲選択が終わるとフォーカスは元のアプリへ返ります——更新ダイアログやメニューが作業中の画面の前に割り込むことはありません
- **アプリ内アップデート**：リリースノートをその場で確認、ダウンロード〜インストールまでワンステップ、インストーラは sha256 検証を強制
- ログイン時に起動、収録中のおやすみモード（ショートカット）、完了通知（Finder で表示）、ディスプレイのホットプラグ対応、中国語 / 英語 UI

## インストール

### Homebrew（推奨）

```bash
brew tap yueseqaz/sakura-cap https://github.com/yueseqaz/Sakura-Cap
brew trust yueseqaz/sakura-cap          # 新しい Homebrew ではサードパーティ Tap の信頼が先に必要
brew install --cask sakura-cap
```

### ソースからビルド

```bash
git clone https://github.com/yueseqaz/Sakura-Cap.git
cd Sakura-Cap
./run.sh
```

> 本アプリは ad-hoc 署名で、公証（notarization）はしていません。初回起動時にブロックされた場合は、右クリック→「開く」、または「システム設定 → プライバシーとセキュリティ」で許可してください。

## 使い方

1. メニューバーのアイコン →「収録開始 / 録音 / スクリーンショット / 翻訳 / AI / ツール」、または設定したグローバルショートカット
2. 範囲を選ぶと画面下部にフローティング操作バーが出ます：解像度を選び、マイク / システムサウンド / カメラ / クリックマーク / キー表示を切り替え、**▶** で開始
3. 収録中は一時停止 / 再開 / 停止が可能。スクリーンショット / OCR / スクロールキャプチャは「スクリーンショット」サブメニューに（スクロールキャプチャは範囲選択後に自動 / 手動を選択）
4. 収録終了後は**ビデオワークベンチ**へ（トリミング / フォーカス / 注釈 / MP4・GIF・フレーム書き出し）；録音は**オーディオエディタ**へ；スクリーンショット / ロングスクリーンショットは**注釈エディタ**へ（保存・コピー・ピン留め）

## 動作環境

- macOS 13 以降
- 初回使用時に**画面収録**権限が必要です。マイク・カメラ・入力監視は任意（許可がない場合はその機能だけが無効になり、収録自体には影響しません）

## 開発

技術スタック、ビルド方法、署名と権限、内部規約や既知の落とし穴 → **[docs/DEVELOPMENT.md](docs/DEVELOPMENT.md)**（中国語）

- Swift 5.9 + SwiftUI / AppKit。収録は ScreenCaptureKit、エンコードは AVFoundation、OCR は Vision
- サードパーティ依存ゼロ・システムフレームワークのみ。Command Line Tools だけでビルドし、`.xcodeproj` は一切ありません
