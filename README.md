# Sakura-Cap

**菜单栏常驻的极简 Mac 录屏工具。** 轻、快、干净——点一下菜单栏就能开录，录完顺手裁一刀。

Sakura-Cap 只想把「把屏幕录下来」这件事做好：无 Dock 图标、无多余窗口，启动快、占用低。录制前在悬浮控制条上就地调好分辨率和音视频，录完自动打开裁剪页。

## 特性

- **全屏 / 区域录制**：全屏支持单屏或所有显示器并行各存一份；区域用蓝框拖拽框选
- **确认再开录**：选定范围后进入「待开始」，在悬浮控制条上点「开始录制」才真正开始，避免误触
- **就地调节**：悬浮控制条上直接切换输出分辨率（原始 / 1080p / 720p）与麦克风、系统声音、摄像头
- **暂停 / 继续**：暂停时段从时间轴剔除，输出无缝、不残留静帧
- **录制辅助**：鼠标点击标记（指向箭头）、键盘按键显示、开始 / 结束提示音
- **摄像头画中画**：录制时在角落叠一个可拖动的圆角摄像头小窗
- **录后即裁剪**：录制完成自动打开裁剪页，拖动区间、只循环预览选中片段，导出为新文件（可选删除原文件）
- **其它**：3 秒倒计时、全局快捷键、开机自启、录屏勿扰、完成通知（可一键在 Finder 显示）、显示器热插拔

## 安装

### Homebrew（推荐）

```bash
brew tap yueseqaz/sakura-cap https://github.com/yueseqaz/Sakura-Cap
brew trust yueseqaz/sakura-cap          # 新版 Homebrew 需先信任第三方 Tap
brew install --cask sakura-cap
```

### 从源码

```bash
git clone https://github.com/yueseqaz/Sakura-Cap.git
cd Sakura-Cap
./run.sh
```

> 应用为 ad-hoc 签名、未公证。首次打开若被拦截，请右键「打开」，或在「系统设置 → 隐私与安全性」中允许。

## 使用

1. 点菜单栏图标 →「开始录制 → 全屏录制 / 框选区域」，或直接按全局快捷键（默认 **⌘⇧R**）
2. 选好范围后，屏幕底部弹出悬浮控制条：选分辨率、开关麦克风 / 系统声音 / 摄像头，点「开始录制」
3. 录制中可**暂停 / 继续 / 停止**；也可以从菜单栏图标操作
4. 停止后自动打开**裁剪页**：拖动时间轴上的两个把手选择保留区间，可循环预览，点「导出」（可选删除原文件）

## 系统要求

- macOS 13 或更高
- 首次使用需授予**屏幕录制**权限；麦克风、摄像头、输入监控按需授予（缺失只会让对应功能不可用，不影响录制本身）
