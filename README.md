# Sakura-Cap

**[中文](README.md)** | **[English](README.en.md)** | **[日本語](README.ja.md)**

**菜单栏常驻的极简 Mac 录屏 / 录音 / 截图 / AI 工具。** 轻、快、干净——点一下菜单栏就能开录，录完顺手剪一剪、标一标，截图取字一步到位，还能截屏问 AI。

Sakura-Cap 只想把「把屏幕录下来 / 截下来」这件事做好：无 Dock 图标、无多余窗口，启动快、占用低。录制前在悬浮控制条上就地调好分辨率、麦克风、摄像头、点击标记与按键显示；录完自动进后期工作台；截图直接进标注编辑器。

## 功能

**录屏**
- 全屏（单屏 / 所有显示器并行各存一份）、框选区域、窗口录制（系统共享选择器）
- 悬浮控制条：待开始时点 ▶ 才真正开录；录制中可暂停 / 继续 / 停止
- 就地调节：输出分辨率（原始 / 1080p / 720p）、麦克风、系统声音、摄像头、点击标记、键盘按键显示
- 暂停时段从时间轴剔除，输出无缝
- 录制辅助：鼠标点击标记（指向箭头）、键盘按键显示、开始 / 结束提示音、摄像头画中画、3 秒倒计时

**录音**
- 菜单栏一键录音：系统声音 / 麦克风 / 两者同时，m4a 输出、系统声与麦克风**分轨**
- 支持暂停 / 继续，暂停间隙自动无缝衔接
- 悬浮录音条：脉动红点 + 律动条 + 计时，可拖动，不进入截屏 / 录屏画面
- 录音结束自动进音频编辑器（可在设置关闭）

**截图**
- 全屏截图 / 区域截图
- **OCR**：框选后系统 Vision 离线识别，文字直接进剪贴板
- **识别二维码**：框选识别内容并复制
- **上传图床**：标注编辑器右侧一键上传整图（含标注），支持 **S3 兼容对象存储**（Cloudflare R2 / MinIO / 各云厂商）、**GitHub 仓库**、**自定义接口**（multipart，链接按 JSON 路径或正则解析）；成功后链接按所选格式（纯链接 / Markdown / HTML）自动复制到剪贴板
- **滚动截屏（长截图）**：框选后先选「自动滚动 / 手动滚动」，边滚动边按重叠自动纵向拼接成一张长图，右侧实时预览
  - 自动滚动无需人工干预；手动滚动自己滚页面实时拼接，两者随时可互切
  - 匹配算法对 Retina 非整数滚动落点、固定顶栏/悬浮元素、懒加载内容稳健
  - 控制条与预览窗自动避开选区摆放，不会被截进画面
- 截图完成后**不直接保存**，进入标注编辑器，由你选择保存 / 拷贝到剪贴板 / 丢弃

**翻译与 AI**（共用一套服务配置）
- **文本翻译**窗口 + **识别屏幕翻译**（框选 → OCR → AI 翻译），可配翻译风格
- **AI 聊天**：Markdown 完整渲染、流式输出（生成中可停止）、图片附件、⏎ 发送 / ⇧⏎ 换行
- **截屏问 AI**：直接给图（视觉模型）或先 OCR 带文字（适配纯文本模型）
- **标注页「问 AI」**：整图（含标注）直接发问
- **聊天记录**：会话列表管理、彻底删除（连同图片文件）；超长对话自动滚动摘要，不丢上下文
- 兼容 **OpenAI Chat / OpenAI Responses / Anthropic** 三种接口格式，均支持流式与多模态图片

**后期：视频工作台**（录制完成后自动进入）
- 多轨时间轴：视频缩略图条、系统声 / 麦克风分轨波形、聚焦轨、标注轨
- 剪辑：分割（S）、删除、拖边缘裁剪、拖动排序、撤销重做（⌘Z / ⇧⌘Z）、磁吸吸附
- 轨道上直接拖拽创建段：聚焦段、标注段、音量段，两端夹点拉伸调整范围
- **画面聚焦**：在预览上框选区域，1–6× 独立调节放大
- 就地标注：画笔 / 箭头 / 形状 / 文字 / 序号 / 马赛克，工具栏悬浮在预览下方
- 音频：整轨音量与静音、音量段（局部静音 / 降音量）、淡入淡出
- 导出 **MP4（无编辑直通秒出）/ GIF / 截帧**；空格播放、←→ 逐帧（⇧ 跳 1 秒）、⌘滚轮缩放时间轴

**后期：音频编辑器**
- 上部大波形（分音轨、剪掉区域压暗、可拖动定位），下部片段行 + 音轨音量行
- 片段裁剪 / 分割 / 排序；音量段、淡入淡出、片段静音、音量 0–200%
- 导出 m4a（无编辑直通秒出）；空格 / ←→ / S / ⌘Z 快捷键
- 菜单「编辑音频…」可直接编辑任意音频文件

**标注编辑器**（截图后与「标注图片…」共用）
- 工具：画笔、箭头、矩形、文字、序号、马赛克（像素块 / 模糊 / 六边形）、裁剪
- 已画的内容可**二次编辑**：选中后移动、改颜色、改粗细、改箭头方向、删除
- 撤销 / 重做；滚轮缩放、⌘+滚轮平移、一键「适应」窗口
- 裁剪即时生效（画面与标注一起裁）
- **「定住」**：把结果干干净净地贴在屏幕上（红虚线框、可拖动、滚轮/按钮等比缩放、右上角关闭）

**其它**
- 全局快捷键：全屏/窗口/区域录制、全屏/区域截图、OCR、滚动截屏，**默认留空、由你设置**
- 工具菜单：**屏幕标注**（全屏即时涂鸦）、**镜头预览**（摄像头浮窗）、标注图片、裁剪视频、编辑音频、**对比**（双图并排完整对比）
- 摄像头画中画带**剪刀按钮**：一键截取当前帧进标注编辑器
- 麦克风 / 摄像头可选具体设备（设置与 HUD 都能选）
- 权限集中在一个「权限」Tab：屏幕录制 / 麦克风 / 输入监控 / 摄像头；麦克风权限只在真正使用时才申请，不打扰
- 框选结束后焦点自动还给原应用，不会把更新弹窗/菜单顶到你正在操作的页面前
- **应用内检查更新**：发布说明就地查看、下载安装一步完成，安装包强制 sha256 校验
- 开机自启、录屏勿扰（快捷指令）、完成通知（一键在 Finder 显示）、显示器热插拔、中英双语

## 安装

### Homebrew（推荐）

```bash
brew tap yueseqaz/sakura-cap https://github.com/yueseqaz/Sakura-Cap
brew trust yueseqaz/sakura-cap          # 新版 Homebrew 需先信任第三方 Tap
brew install --cask sakura-cap
```

### 从源码构建

```bash
git clone https://github.com/yueseqaz/Sakura-Cap.git
cd Sakura-Cap
./run.sh
```

> 应用为 ad-hoc 签名、未公证。首次打开若被拦截，请右键「打开」，或在「系统设置 → 隐私与安全性」中允许。

## 使用

1. 点菜单栏图标 →「开始录制 / 录音 / 截屏 / 翻译 / AI / 工具」，或按你设置的全局快捷键
2. 选好范围后，屏幕底部弹出悬浮控制条：选分辨率、开关麦克风/系统声音/摄像头/点击标记/按键显示，点 **▶** 开始
3. 录制中可**暂停 / 继续 / 停止**；截图 / OCR / 滚动截屏见「截图」子菜单（滚动截屏框选后先选自动 / 手动滚动）
4. 录制停止后自动进**后期工作台**（裁剪 / 聚焦 / 标注 / 导出 MP4 / GIF / 截帧）；录音进**音频编辑器**；截图 / 长图进**标注编辑器**（可保存、拷贝或「定住」）

## 系统要求

- macOS 13 或更高
- 首次使用需授予**屏幕录制**权限；麦克风、摄像头、输入监控按需授予（缺失只让对应功能不可用，不影响录制本身）

## 开发

技术栈、构建方式、签名与权限、内部约定与已知坑 → **[docs/DEVELOPMENT.md](docs/DEVELOPMENT.md)**

- 技术栈：Swift 5.9 + SwiftUI / AppKit；采集 ScreenCaptureKit；编码 AVFoundation；OCR 用 Vision
